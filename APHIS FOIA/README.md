# Description
This dir contains docs for preparing a FOIA request to USDA APHIS.
the goal of the FOIA request is to get information on the actual FBS concentrations used by vaccine manufacturers to satisfy the testing required by VIRPRO103.04.

VIRPRO103.04
growth medium FBS%: 5-10
maintenance medium FBS%: 5-20

The maintenance medium range is large. This FOIA is indended to satify the curiousity of the FBS% used in maintenance medium by vaccine manfacturers who are applying for licensure.

# How to submit
USDA Public Access Link (PAL) — the official online FOIA portal for USDA (including APHIS).
Link: https://securefoia.usda.gov/

APHIS FOIA page with instructions: https://www.aphis.usda.gov/freedom-information-act/how-submit-foia-request
